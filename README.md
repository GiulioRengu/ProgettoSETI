# ProgettoSETI
Progetto di SETI 25/26 Biglieri - Rengucci

Questa reposiotory è dedicata al progetto di SETI "IPortBook", un sistema simile ad un socialnetwork dove però gli utenti comunicano tramite datagrammi UDP.

Istruzioni per compilare ed eseguire:
- fare make all da terminale
- eseguire il server tramite il comando: ./server_exe <porta tcp> <flag opzionale -v>
- eseguire il client tramite il comando: ./client_exe <ip server> <porta tcp del server> <porta UDP> <flag opzionale -v>
